# One Percent — the page it is sold from

One static page at `farahbrunache.com`. No build, no dependencies, no secrets.

The checkout, the claim page and the payment screen are in `one-percent-app`, deployed to
`app.farahbrunache.com`. The Pay for a session button links there.

## Files

| Path | What it is |
|---|---|
| `index.html` | The page |
| `style.css` | Its styles |

## Checking a change

Render at 390 pixels and look, rather than assuming. The layout is one phone-width column at
every viewport, and the theme is dark only — set the browser to dark or you will be checking
a page nobody sees.
